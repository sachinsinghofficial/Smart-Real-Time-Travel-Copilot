# TravelSetu Phase 7

Smart Travel Marketplace + multi-factor safety/risk engine.

Features: curated demo inventory for buses/flights/cars/hotels, budget-aware recommendation logic, demo booking stored in localStorage, rich risk assessment across traffic, road status, landslide, flood, snow, wildfire, visibility, transport delay and local alerts.

No live booking or live road-incident provider is claimed; inventory/risk scenarios are clearly demo data until official supplier feeds are connected.
